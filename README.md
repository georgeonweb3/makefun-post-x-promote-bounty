Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty. The entry is one post of my own on X that links to make.fun's make-your-own-bounty post, carries a photo made for it (the make.fun lockup from the official press pack, used as-is, on a graphic with my own words), and asks the question every builder has an answer to: what bounty would you make? `POST.json` names the post; `main.ts` copies it to the output directory for the gate, which reads the post's replies, reposts and quotes from X. Places go by replies + reposts + quotes, top 50 share $250.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
